# Educación - Análisis Estadístico

## Descripción

Análisis exploratorio y estadístico del rendimiento académico de
estudiantes utilizando Python.

El proyecto busca identificar patrones y asociaciones entre las
calificaciones académicas y diferentes variables relacionadas con el
estudiante, su entorno familiar y sus hábitos de estudio.

## Dataset

El dataset contiene:

- 649 estudiantes
- 33 variables
- Calificaciones de tres periodos académicos: N1, N2 y N3

## Herramientas utilizadas

- Python
- Pandas
- NumPy
- Matplotlib
- Seaborn
- SciPy
- Jupyter Notebook

## Análisis realizado


- Estadística descriptiva
- Distribución de las calificaciones N1, N2 y N3
- Correlaciones entre variables
- Relación entre N2 y N3
- Horas de estudio y rendimiento académico
- Asignaturas reprobadas y rendimiento académico
- Educación de los padres y rendimiento académico
- Prueba t de diferencia de medias
- Tamaño del efecto mediante Cohen's d
- Visualización mediante gráficos y KPIs

## Principales hallazgos

- El promedio de N3 fue de 11,91.
- N2 presentó una fuerte correlación positiva con N3 (r = 0,919).
- Las horas de estudio presentaron una correlación positiva con N3
  (r = 0,250).
- Las asignaturas reprobadas presentaron una correlación negativa con
  N3 (r = -0,393).
- Los estudiantes con y sin asignaturas reprobadas presentaron
  diferencias estadísticamente significativas en sus medias de N3.
- La educación de la madre y del padre presentó asociaciones positivas
  con N3.

Las correlaciones y diferencias observadas describen asociaciones en
la muestra analizada y no deben interpretarse como relaciones causales.
